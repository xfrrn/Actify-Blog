这是一篇**示例技术笔记**，介绍当前网站已经使用的数据组织方式。

## 一份项目资料

每个作品单独放在 `content/projects/` 下的 Markdown 文件中，首页与项目汇总页读取同一份资料。新增文件就会自动收录，修改内容后两处展示一起更新。

```yaml title="content/projects/my-tool.md"
---
name: "My Tool"
description:
  en: "A short English introduction."
  zh: "一个小工具的中文简介。"
technologies: ["TypeScript"]
featured: true
order: 50
draft: true
---
```

## 首页只保留精选

`featured: true` 的项目会出现在首页。`/projects` 展示全部非草稿项目，并复用同一张项目卡片。图片、状态、GitHub 与 Demo 都属于项目数据。

没有公开源码的项目可以不填 GitHub 链接。组件只展示已经填写的有效入口，避免出现无法访问的占位链接。

## 什么时候增加详情页

当一个项目需要独立讲清背景、过程与结果时，再增加详情页。第一版先用项目简介、链接和相关博客完成展示。
